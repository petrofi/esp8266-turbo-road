# Contributing

Katkılar memnuniyetle kabul edilir.

1. Repoyu fork edin.
2. Yeni bir branch oluşturun.
3. Değişikliklerinizi küçük ve anlaşılır commit'lerle yapın.
4. NodeMCU V3 ESP8266 üzerinde derleme/test yapın.
5. Pull Request açın.

Lütfen donanım bağlantılarını değiştiriyorsanız README ve `docs/wiring.svg` dosyasını da güncelleyin.
